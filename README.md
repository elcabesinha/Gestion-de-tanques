Sistema de Gestión de Tanques

Aplicación web desarrollada para la administración y control de tanques de combustible en una estación de servicio. El sistema permite registrar tanques, controlar ventas y realizar recargas de combustible de manera organizada y eficiente.

Funcionalidades principales:
Registro de nuevos tanques
Control de capacidad y galones disponibles
Registro de ventas de combustible
Recarga de tanques
Visualización del estado actual de los tanques
Historial de últimas ventas y recargas
Interfaz amigable y fácil de usar

Objetivo del proyecto:
Facilitar el control y monitoreo del combustible almacenado en los tanques, permitiendo llevar un registro actualizado de las ventas y recargas realizadas dentro de la estación de servicio.



Tank Management System

Web application developed for the administration and control of fuel tanks in a gas station. The system allows users to register tanks, manage fuel sales, and perform fuel refills in an organized and efficient way.

Main Features:
Register new tanks
Manage tank capacity and available gallons
Record fuel sales
Refill fuel tanks
Display current tank status
View recent sales and refill history
User-friendly and intuitive interface

Project Objective:
To facilitate the control and monitoring of fuel stored in tanks by keeping an updated record of sales and refills within the gas station.
